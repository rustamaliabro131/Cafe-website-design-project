# ☕ Coffee Shop — Interactive Menu & Ordering Web App

A modern, responsive, single-page coffee shop menu and interactive customization web application inspired by the **Starbucks Menu** design language. Designed to reduce decision fatigue and deliver a frictionless mobile-first ordering experience.

## ✨ Key Features

- **Starbucks-Inspired Visual Hierarchy:** Clean circular product cards on warm cream surfaces (`#F9F6F0`), paired with deep forest green (`#1E3932`) brand accents and geometric `Poppins` typography.
- **Sticky Dual-Navigation System:** Persistent top header with live cart counter, sticky sub-navigation with quick-filter tabs (*All Menu*, *Featured*, *Favorites*), and a sticky desktop category sidebar that collapses into a scrollable pill bar on mobile.
- **Real-Time Search & Filtering:** Instant search bar and category navigation across *Drinks* (Hot Coffees, Cold Coffees, Signature Lattes, Matcha & Tea) and *Food* (Artisan Bakery, Breakfast).
- **Interactive Drink Customization Drawer:** Click any menu item to open a slide-over customization panel with dynamic pricing for:
  - Cup Sizes (*Short, Tall, Grande, Venti*)
  - Temperature Toggle (*Hot / Iced*)
  - Milk Alternatives (*Whole, Oat, Almond, Soy*)
  - Syrup & Sweetness Options
- **Favorites & Live Cart Drawer:** Save favorite drinks with one click and manage order quantities, customizations, and subtotals in a functional slide-over shopping cart.

## 🛠️ Design & Development Workflow

This project was built using a rapid UI-to-Code pipeline:
1. **UI/UX Prototyping:** Designed in **Google Stitch** using structured layout and design-system prompting.
2. **Frontend Engineering:** Developed and refined in **VS Code IDE** using semantic HTML5, Tailwind CSS, and Vanilla JavaScript.
